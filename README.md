A [make.fun](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce) bounty entry: a program that writes one single-line joke giving an excuse for a missed deadline.

## The entry

> I missed the deadline because I spent all day writing the perfect apology for missing the deadline.

## Run

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (99 characters, one line, under the 200-character cap). It self-checks the gate before writing: the line must be 1–200 characters, a single line, and not only whitespace.
